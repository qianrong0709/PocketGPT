# PocketGPT 中文说明

[返回项目主页](../README.md)

PocketGPT 将蛋白口袋、分子性质、单片段和蛋白–配体相互作用指纹结合到自回归分子生成中，输出分子的 SMILES，不直接构建配体三维坐标。

## 训练分为两个阶段

1. **性质＋单片段条件预训练**：使用母分子 SMILES、LogP/QED/TPSA/SAS 和单片段，不使用口袋或 IFP。
2. **结构–功能条件微调**：使用已有 CSV 中的口袋向量，加上性质、单片段和六类 IFP，不需要重新计算全量口袋向量，也不重新训练 DeeplyTough。

这是当前开发版本的训练方案，不等于已经核对并复现了论文全部训练细节。当前按复合物分组的微调验证，也不能称为“未见蛋白泛化”。

## 别人使用时需要提供什么？

待重构版本和对应权重正式发布后，用户按需要选择条件：

| 条件 | 用户提供的内容 |
| --- | --- |
| 口袋 | 蛋白 PDB 和对应的口袋 PDB；整个蛋白文件本身不能确定结合位点 |
| 性质 | LogP、QED、TPSA、SAS 中一个或多个目标值 |
| 片段 | 一个片段 SMILES |
| IFP | 氢键、疏水、π–π、盐桥、π–阳离子、卤键六类二进制目标 |

新口袋由配置好的 DeeplyTough 流程编码并缓存，其他条件分别编码后参与融合和生成。口袋编码器是冻结的，自动流程不代表生成损失会反向训练 DeeplyTough。历史向量和新编码结果的兼容性仍须在发布前验证。

性质和 IFP 目标不是仅凭蛋白就能全部自动确定的：观察到的 IFP 需要配体及其结合姿势；片段提取需要参考分子及明确规则。条件控制是学习引导，不保证输出分子一定满足所有要求。

**普通推理用户不需要准备训练 JSONL。** JSONL 是开发版本内部的训练数据存储方式；JSON 也可以只是程序接口的请求格式。正式发布应提供直接传结构文件和目标值的使用示例。
